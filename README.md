# iSupply Scan – ke stažení

Diagnostika iPhonů a iPadů pro Windows 10 / 11 (64bit) a macOS (beta) – **https://isupply-scan.cz**

## iSupply Scan (vše v jednom)

[**⬇ iSupply.Scan.exe** – nejnovější verze](https://github.com/Bot-owner/isupply-scan-download/releases/latest/download/iSupply.Scan.exe)

Jeden soubor, ve kterém je všechno včetně USB ovladače Apple – nic dalšího se nestahuje ani neinstaluje.

1. Spusť `iSupply.Scan.exe`. Když Windows ukáže „Systém Windows ochránil váš počítač“ → **Další informace → Přesto spustit**.
2. Na počítači bez ovladače Apple si ho aplikace při prvním spuštění nainstaluje sama – Windows se zeptá na oprávnění správce, potvrď **Ano**. Když ovladač už na počítači je, tenhle krok se přeskočí.
3. Aktivuj licenci (záložka *Activate licence*) a připoj iPhone.

## iSupply Scan pro macOS (Beta)

[**⬇ iSupply.Scan.dmg** – beta pro Macy s Apple Silicon](https://github.com/Bot-owner/isupply-scan-download/raw/macos-beta/iSupply.Scan.dmg) · macOS 15 nebo novější

1. Otevři `.dmg` a přetáhni **iSupply Scan** do Aplikací.
2. Beta zatím není podepsaná u Applu, proto ji macOS napoprvé zablokuje: klikni na **Hotovo**, otevři
   **Nastavení systému → Soukromí a zabezpečení**, sjeď dolů k části Zabezpečení a u iSupply Scan klikni na
   **Přesto otevřít**. Příště už se macOS neptá.
3. Aktivuj licenci a připoj iPhone. Nic dalšího se neinstaluje – služba Apple pro iPhony je součást macOS.
